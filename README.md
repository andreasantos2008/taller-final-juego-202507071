# EL JUEGO DE LA MANZANA

Este juego tratara en que el usuario tendra que ir corriendo, hasta que se encuentre con un obstáculo, el cual se podrá pasar respondiendo correctamente las preguntas que se le presentan, cada vez que acierte ganara una manzanita, la cual podrá hacer que el jugador avance sin responder la pregunta solo si el usuario desea usarla, sin embargo, si no acierta perdera la manzanita, el usuario solo podrá tener una manzanita, aunque acierte las preguntas solo podrá tener una manzanita en el inventario, el juego tendra un total de 30 niveles, las preguntas son fáciles.
